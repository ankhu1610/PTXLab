## 1. Objectives

1. **Typed Three-Address Code (TAC) IR:**
   * Design a clean, linear, strongly-typed Three-Address Code Intermediate Representation.
   * Virtual register allocation model (`%v0, %v1, ...` and predicates `%p0, %p1, ...`).
   * Explicit representation of memory indexing via `elemaddr`, `load`, and `store`.
2. **Control Flow Graph (CFG) & Basic Blocks:**
   * `BasicBlock` structure: explicit label, straight-line instruction vector, and **strictly one terminator** at the end.
   * Bidirectional edge maintenance (`predecessors` and `successors`).
   * Explicit kernel function structure with a designated single entry block (no predecessors).
3. **AST-to-IR Lowering Engine (`Lowering`):**
   * Translate high-level statements (`decl`, `assign`, `if-else`, `while`, `for`, `return`) into CFG blocks.
   * Implement **jumping code** for short-circuit boolean logic (`&&`, `||`, `!`) and condition branching without redundant materialization of predicates where possible.
   * Maintain a mapping from AST source variables to IR virtual registers.
4. **IR Textual Printer & Formatting:**
   * Provide human-readable IR formatting with clear basic block labels, instruction opcodes, and type signatures.
   * Integrate CLI option `kcc --dump-ir <input.kc>`.
5. **IR Verifier (`IRVerifier`):**
   * Enforce structural and semantic invariants before optimization or code generation:
     1. Every block ends with exactly one terminator (`br`, `condbr`, `ret`).
     2. All branch targets reference existing blocks within the same function.
     3. Predecessor and successor edge lists are consistent and symmetrical.
     4. Entry block has zero predecessors.
     5. Instruction operand types match their signature requirements.
     6. Every register used is guaranteed to be defined before use along all execution paths.
6. **IR Reference Interpreter (`Oracle O2`):**
   * Directly evaluate the CFG IR on the CPU.
   * Model memory buffers and 1D GPU launches (`gridDim`, `blockDim`).
   * Enforce identical Undefined Behavior (UB) traps as O1 (division by zero, integer overflow on `INT_MIN / -1`, shift bounds, buffer out-of-bounds).
7. **Multi-Oracle Differential Testing:**
   * Verify **O1 (AST Interpreter) == O2 (IR Interpreter)** bit-for-bit across the test corpus.

## 3. IR Specification & Instruction Set Architecture

### 3.1 Types (`IRType`)
* `i32`: 32-bit signed integer.
* `f32`: 32-bit IEEE 754 single-precision float.
* `pred`: 1-bit boolean predicate register.
* `ptr_i32`: 64-bit address referencing `i32` global memory.
* `ptr_f32`: 64-bit address referencing `f32` global memory.

### 3.2 Operands (`IROperand`)
* **Register:** `%v0`, `%v1`, ... (types `i32`, `f32`, `ptr_i32`, `ptr_f32`) or `%p0`, `%p1`, ... (type `pred`).
* **Constant:** Integer (`123`), Float (`3.14f`), or Boolean (`true`, `false`).

### 3.3 Instruction Set

| Opcode | Syntax | Semantics |
|---|---|---|
| `const` | `%v = const T <lit>` | Loads immediate constant into register |
| `copy` | `%v = copy %u` | Register-to-register copy |
| `param` | `%v = param <index>` | Loads kernel formal parameter $k$ |
| `special` | `%v = special <tid_x \| ctaid_x \| ntid_x>` | Reads GPU hardware thread register |
| `add` | `%v = add %a, %b` | 32-bit integer addition (two's complement wrap) |
| `sub` | `%v = sub %a, %b` | 32-bit integer subtraction |
| `mul` | `%v = mul %a, %b` | 32-bit integer multiplication |
| `div` | `%v = div %a, %b` | 32-bit integer division (truncating toward zero; traps on 0 or `INT_MIN/-1`) |
| `rem` | `%v = rem %a, %b` | 32-bit integer remainder (traps on 0 or `INT_MIN/-1`) |
| `and` | `%v = and %a, %b` | Bitwise AND on `i32` |
| `or` | `%v = or %a, %b` | Bitwise OR on `i32` |
| `xor` | `%v = xor %a, %b` | Bitwise XOR on `i32` |
| `shl` | `%v = shl %a, %b` | Shift left (traps if count $\notin [0, 31]$) |
| `shr` | `%v = shr %a, %b` | Arithmetic shift right (traps if count $\notin [0, 31]$) |
| `neg` | `%v = neg %a` | Two's-complement negation on `i32` |
| `not` | `%v = not %a` | Bitwise NOT on `i32` |
| `fadd` | `%v = fadd %a, %b` | IEEE 754 single-precision addition |
| `fsub` | `%v = fsub %a, %b` | IEEE 754 single-precision subtraction |
| `fmul` | `%v = fmul %a, %b` | IEEE 754 single-precision multiplication |
| `fdiv` | `%v = fdiv %a, %b` | IEEE 754 single-precision division |
| `fneg` | `%v = fneg %a` | IEEE 754 floating-point negation |
| `cmp` | `%p = cmp.<cond> %a, %b` | Relational/Equality check yielding `pred` (`eq, ne, lt, le, gt, ge`) |
| `cvt` | `%v = cvt.<i32_to_f32 \| f32_to_i32> %a` | Explicit scalar type conversion |
| `elemaddr` | `%a = elemaddr %base, %idx` | Computes element address `base + idx * sizeof(T)` |
| `load` | `%v = load %addr` | Global memory read from pointer address |
| `store` | `store %addr, %v` | Global memory write to pointer address |

### 3.4 Terminators (Block Endpoints)

| Terminator | Syntax | Behavior |
|---|---|---|
| `br` | `br <target_block>` | Unconditional jump to destination block |
| `condbr` | `condbr %p, <then_block>, <else_block>` | Branch to `then_block` if `%p == true`, else `else_block` |
| `ret` | `ret` | Return control from kernel function |

## 4. Control Flow Graph Lowering Schemes

### 4.1 If-Else Statement Lowering
```
            [ current_block ]
                    │
            (evaluate cond -> %p)
                    │
         condbr %p, bb_then, bb_else
                /         \
               ▼           ▼
        [ bb_then ]     [ bb_else ]
        (then body)     (else body)
               \           /
             br bb_join  br bb_join
                 \       /
                  ▼     ▼
               [ bb_join ]
```

### 4.2 While Loop Lowering
```
            [ current_block ]
                    │
                 br bb_header
                    │
                    ▼
          ┌──► [ bb_header ] ◄─────────────────┐
          │    (eval cond -> %p)               │
          │    condbr %p, bb_body, bb_exit     │
          │            │                       │
          │            ▼                       │
          │        [ bb_body ]                 │
          │        (loop body)                 │
          │            │                       │
          │         br bb_header ──────────────┘
          │
          ▼
      [ bb_exit ]
```

### 4.3 Short-Circuiting Boolean Logic (Jumping Code)
Expressions like `a && b` or `a || b` are lowered without executing the right-hand side if the left-hand side suffices:
* For `A && B` in a branch: if `A` is false, jump directly to `bb_false`; only evaluate `B` if `A` is true.
* For `A || B` in a branch: if `A` is true, jump directly to `bb_true`; only evaluate `B` if `A` is false.

## 5. IR Verifier Rules & Invariants

The `IRVerifier` performs structural validation and reports precise violations:

1. **Terminator Invariant:** Every `BasicBlock` must contain non-terminator instructions followed by **exactly one** terminator instruction.
2. **Branch Target Validity:** Every destination label in `br` and `condbr` must resolve to an existing `BasicBlock` within the same parent `Function`.
3. **CFG Edge Symmetry:** For every block $A$ with successor $B$, block $B$ must list block $A$ as a predecessor.
4. **Entry Block Isolation:** The function entry block must have **zero predecessors**.
5. **Type Consistency:**
   * Arithmetic operations (`add`, `fadd`) must have matching operand types.
   * `cmp` operands must match and output must be `pred`.
   * `condbr` condition operand must be of type `pred`.
   * `elemaddr` base must be `ptr_i32` or `ptr_f32`, and index must be `i32`.
   * `load` and `store` must operate on pointer registers matching element types.
6. **Defined-Before-Use:** Every virtual register consumed as an operand must have a reaching definition on all CFG paths prior to that instruction.

## 6. IR Reference Interpreter (`Oracle O2`)

* **Execution Model:**
  * Simulates a 1D grid launch across `gridDim * blockDim` threads.
  * For each thread $(tid, ctaid)$, initializes registers and starts at `entry` block.
  * Executes instructions sequentially until reaching the terminator.
  * Follows `br` and `condbr` to the next block until reaching `ret`.
* **State Management:**
  * Virtual register store: `std::unordered_map<int, Value> registers_`.
  * Shared global buffers: `BufferManager` backing `ptr_i32` and `ptr_f32`.
* **Traps & Parity with O1:**
  * Replicates identical UB traps for division by zero, signed overflow, shift bounds out of $[0, 31]$, and buffer out-of-bounds access.

## 7. Acceptance Criteria

1. **IR Data Structures:** All instructions, blocks, functions, and module structures defined and unit-tested.
2. **AST Lowering:** Successfully lowers `saxpy.kc` and test kernels into clean, valid CFGs.
3. **IR Verifier:**
   * Passes on all valid lowered kernels.
   * Catches hand-crafted invalid IR (missing terminators, mismatched types, invalid targets).
4. **IR Text Printer:** Emits clear, parseable IR text (`kcc --dump-ir <file.kc>`).
5. **Differential Verification (O1 == O2):**
   * The IR Interpreter (O2) executes lowered kernels and produces bit-exact identical buffer outputs to the AST Interpreter (O1).
6. **All CTest suites pass 100% green with zero compiler warnings.**
