## 1. Objectives

1. **PTX Code Generator (`PTXEmitter`):**
   * Translate verified Typed TAC IR (`ptxlab::ir::Module`, `Function`, `BasicBlock`, `Instruction`) into syntactically valid, high-performance NVIDIA Parallel Thread Execution (PTX) virtual ISA assembly.
2. **Target Specification & Directive Prologue:**
   * Standardize on `.version 7.0`, `.target sm_75`, `.address_size 64`.
   * Ensures binary compatibility across modern NVIDIA architectures (Turing `sm_75`, Ampere `sm_80`/`sm_86`, Ada Lovelace `sm_89`, Hopper `sm_90`, and Blackwell `sm_100`/`sm_120`).
3. **Register Bank Management:**
   * Allocate typed virtual registers using PTX bank declarations:
     * 32-bit integers: `.reg .b32 %r<0..N>;`
     * 32-bit floats: `.reg .f32 %f<0..N>;`
     * 64-bit pointers & addresses: `.reg .b64 %rd<0..N>;`
     * Predicates (1-bit booleans): `.reg .pred %p<0..N>;`
   * Pre-scan kernel instructions to compute high-water marks for each bank and emit precise `.reg` directives at entry.
4. **Parameter Passing & Kernel ABI:**
   * Declare kernel parameters in `.visible .entry` parameter lists:
     * Pointers: `.param .u64 <name>`
     * 32-bit Scalars: `.param .u32 <name>` (or `.param .f32 <name>`)
   * Load parameter values in the entry block using `ld.param` instructions.
   * Explicitly convert parameter pointer addresses from generic space to global space via `cvta.to.global.u64`.
5. **Special Register Intrinsics:**
   * Map GPU hardware thread indexing intrinsics to PTX special registers:
     * `special tid_x`   $\to$ `mov.u32 %r, %tid.x;`
     * `special ctaid_x` $\to$ `mov.u32 %r, %ctaid.x;`
     * `special ntid_x`  $\to$ `mov.u32 %r, %ntid.x;`
6. **Instruction Mapping & Semantics:**
   * Implement strict mapping for all arithmetic, bitwise, unary, memory, and control flow instructions.
   * Floating-point operations explicitly enforce IEEE 754 round-to-nearest-even (`.rn`) modifiers to prevent non-deterministic FMA contraction and match host evaluation.
   * Address calculations (`elemaddr`) emit sign-extended wide multiplication (`mul.wide.s32`) scaled by element byte size followed by 64-bit pointer addition (`add.s64`).
7. **Control Flow & Predication:**
   * Map IR Basic Block labels directly to PTX jump targets.
   * Unconditional branches: `bra <target>;`
   * Conditional branches: `@%p bra <target>;`
   * Kernel exit: `ret;`
8. **Compiler Tooling & Unit Testing:**
   * Integrate `--emit-ptx` into `kcc` CLI with optional `-o <output.ptx>` destination.
   * Implement unit testing in `tests/unit/test_ptx_emitter.cpp` covering header directives, parameter conversion, arithmetic, memory indexing, and full `saxpy` emission.

## 3. PTX ISA Mapping Specification

### 3.1 Directives and Prologue

Every generated PTX module begins with:
```ptx
// Generated by PTXLab Mini-Compiler (kcc)
.version 7.0
.target sm_75
.address_size 64
```

### 3.2 Kernel Declaration & Parameter ABI

For kernel: `kernel saxpy(i32 n, f32 a, f32* x, f32* y)`:
```ptx
.visible .entry saxpy(
    .param .u32 param_n,
    .param .f32 param_a,
    .param .u64 param_x,
    .param .u64 param_y
)
{
    // Register bank declarations
    .reg .b32   %r<N>;
    .reg .f32   %f<N>;
    .reg .b64   %rd<N>;
    .reg .pred  %p<N>;

    // Parameter loading & generic-to-global conversion
    ld.param.u32    %r0, [param_n];
    ld.param.f32    %f0, [param_a];
    ld.param.u64    %rd0, [param_x];
    cvta.to.global.u64 %rd1, %rd0;
    ld.param.u64    %rd2, [param_y];
    cvta.to.global.u64 %rd3, %rd2;
```

### 3.3 Instruction Translation Table

| TAC IR Opcode | TAC IR Operands | Emitted PTX Instruction | Semantics & Notes |
|:---|:---|:---|:---|
| `Const` (int) | `%v_dst = const i32 C` | `mov.u32 %r_dst, C;` | Immediate integer constant |
| `Const` (float) | `%v_dst = const f32 C` | `mov.f32 %f_dst, 0fXXXXXXXX;` or `C.0` | IEEE 754 float immediate |
| `Const` (bool) | `%p_dst = const pred B` | `mov.pred %p_dst, 1;` or `0;` | 1-bit predicate immediate |
| `Copy` | `%v_dst = copy %v_src` | `mov.<type> <dst>, <src>;` | Register move / copy |
| `Special` (tid) | `%v_dst = special tid_x` | `mov.u32 %r_dst, %tid.x;` | Thread index in block |
| `Special` (ctaid) | `%v_dst = special ctaid_x` | `mov.u32 %r_dst, %ctaid.x;` | Block/CTA index in grid |
| `Special` (ntid) | `%v_dst = special ntid_x` | `mov.u32 %r_dst, %ntid.x;` | Block dimension ($x$) |
| `Add` (i32) | `%v_dst = add %a, %b` | `add.s32 %r_dst, %r_a, %r_b;` | Two's-complement addition |

| `CmpEq` (i32) | `%p_dst = cmpeq %a, %b` | `setp.eq.s32 %p_dst, %r_a, %r_b;` | Set predicate on equal |
| `CmpNe` (i32) | `%p_dst = cmpne %a, %b` | `setp.ne.s32 %p_dst, %r_a, %r_b;` | Set predicate on not equal |

| `CmpGe` (i32) | `%p_dst = cmpge %a, %b` | `setp.ge.s32 %p_dst, %r_a, %r_b;` | Set predicate on greater equal |

| `Store` (f32) | `store %rd_addr, %v_val` | `st.global.f32 [%rd_addr], %f_val;` | 32-bit float global store |
| `Br` | `br <target>` | `bra <target>;` | Unconditional jump |
| `CondBr` | `condbr %p, <trueBB>, <falseBB>` | `@%p bra <trueBB>;`<br>`bra <falseBB>;` | Guarded branch |
| `Ret` | `ret` | `ret;` | Return from kernel |

## 4. Verification and Testing Strategy

1. **Syntax & Structural Validation:**
   * Unit tests assert header directives `.version 7.0`, `.target sm_75`, `.address_size 64`.
   * Unit tests verify register declarations `.reg .b32`, `.reg .f32`, `.reg .b64`, `.reg .pred`.
   * Unit tests verify that parameter loadings and generic-to-global conversions (`cvta.to.global.u64`) are generated correctly.
2. **Instruction Coverage:**
   * Unit tests for each category: arithmetic (`add`, `sub`, `mul`, `div`), comparisons (`setp`), branches (`bra`, `@%p bra`), and memory (`elemaddr`, `ld.global`, `st.global`).
3. **Golden Kernel Output:**
   * Full test emitting `saxpy.kc` and checking the resulting assembly against expected golden PTX patterns.
