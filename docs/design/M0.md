# Milestone 0 Design Document: Environment & Skeleton Baseline

**Status:** IN PROGRESS  
**Target Date:** Week 1, Days 1–2  
**Owner:** Compiler Pair (Human + AI Assistant)

---

## 1. Objectives

1. Establish a verified, reproducible C++20 build and test baseline on Native Windows.
2. Configure **CMake** and **Ninja** with the **MinGW-w64 (WinLibs UCRT GCC 16.2 / Clang++)** toolchain.
3. Integrate **GoogleTest** via CMake's `FetchContent` (pinned at release `v1.15.2`).
4. Implement an empty `kcc` compiler CLI skeleton (`src/tools/kcc.cpp`) that prints version and help info.
5. Create an automated environment verification script (`scripts/check_env.ps1`) that records exact tool availability and versions into `docs/env-report.txt`.
6. Add an offline PTX baseline smoke test (`tests/ptx_corpus/smoke.ptx`).
7. Maintain `docs/STATUS.md` as the living progress and truthfulness ledger.

## 3. Toolchain & Build Specification

* **C++ Standard:** C++20 (`set(CMAKE_CXX_STANDARD 20)`, `set(CMAKE_CXX_STANDARD_REQUIRED ON)`).
* **Compiler Options:**
  * MinGW GCC / Clang: `-Wall -Wextra -Wpedantic -Wconversion -Wno-unused-parameter`
* **Test Framework:** GoogleTest `v1.15.2` fetched via `FetchContent_Declare`.
* **Output Targets:**
  * `ptxlab_support` (STATIC library)
  * `kcc` (EXECUTABLE)
  * `unit_tests` (EXECUTABLE linked to `GTest::gtest_main`)

---

## 4. Acceptance Criteria (Gate)

1. `check_env.ps1` runs cleanly and records all installed tools into `docs/env-report.txt`.
2. `cmake -B build -G Ninja` configures successfully without errors.
3. `cmake --build build` produces `kcc.exe` and `unit_tests.exe`.
4. `ctest --test-dir build --output-on-failure` executes and passes all tests (100% green).
5. `kcc.exe --version` prints `PTXLab Compiler (kcc) version 0.1.0`.
6. Explain-back questions for M0 are answered and recorded in `docs/learning-log.md`.
