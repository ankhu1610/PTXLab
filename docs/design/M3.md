## 1. Objectives

1. **Scoped Symbol Table:** Implement a hierarchical symbol table managing scopes (Kernel parameters, nested block `{ ... }` scopes), tracking variables, types, and declaration sites.
2. **Semantic Analysis (`Sema`):**
   * **Strict Typing:** No implicit conversions. All binary/unary operations require exact matching types (`i32 op i32 -> i32`, `f32 op f32 -> f32`, relational/logical yielding `bool`).
   * **Explicit Casts:** Type conversion allowed only through explicit `i32(e)` and `f32(e)` calls.
   * **Kernel Pointer Restrictions:** Pointers (`i32*`, `f32*`) are strictly permitted only as kernel parameters (global memory buffers); local pointer variables are rejected.
   * **Mandatory Initializer & Definite Assignment:** Every local variable declaration must have an initializer matching its declared type.
   * **GPU Intrinsics:** Validate `tid_x()`, `ctaid_x()`, `ntid_x()` as zero-argument intrinsics returning `i32`.
   * **Control Flow:** Enforce `bool` conditions for `if`, `while`, and `for`. Kernel `return` must have no return value (`return;`).
3. **AST Reference Interpreter (`Oracle O1`):**
   * Direct tree-walking execution of verified ASTs on the CPU.
   * Simulates 1D GPU kernel thread launches across thread IDs `0 .. (grid * block - 1)`.
   * Manages simulated GPU memory buffers (`i32*`, `f32*`) backed by host arrays.
   * **Strict Undefined Behavior (UB) Traps:**
     * Integer division or modulo by zero (`/ 0`, `% 0`).
     * Two's-complement signed division overflow: `INT_MIN / -1`.
     * Shift counts outside `[0, 31]` for `<<` and `>>`.
     * Out-of-bounds buffer access (`idx < 0 || idx >= buffer_size`).
     * Float-to-int cast overflow or `NaN`.
     * Infinite loop step limit exceeded (default 1,000,000 steps).
4. **CLI Integration:** Add `--run-ast` to `kcc` supporting buffer arguments and thread configurations.
5. **Testing Suite:**
   * $\ge 20$ negative sema tests verifying exact Clang-style diagnostics on semantic violations.
   * Positive execution tests on `saxpy.kc` and arithmetic/logic/loop test kernels.
   * Dedicated UB trap unit tests ensuring every hazardous condition triggers a clean trap.

## 3. Scoped Symbol Table Design

### 3.1 Data Structures
```cpp
struct Symbol {
    std::string name;
    Type type;
    SourceLocation declLoc;
    bool isParam = false;
};

class Scope {
public:
    explicit Scope(Scope* parent = nullptr) : parent_(parent) {}

    bool insert(const Symbol& sym);
    [[nodiscard]] const Symbol* lookup(std::string_view name) const;
    [[nodiscard]] const Symbol* lookupCurrent(std::string_view name) const;
    [[nodiscard]] Scope* parent() const noexcept { return parent_; }

private:
    Scope* parent_ = nullptr;
    std::unordered_map<std::string, Symbol> symbols_;
};

class SymbolTable {
public:
    void enterScope();
    void exitScope();
    bool insert(const Symbol& sym);
    [[nodiscard]] const Symbol* lookup(std::string_view name) const;
    [[nodiscard]] const Symbol* lookupCurrent(std::string_view name) const;

private:
    std::vector<std::unique_ptr<Scope>> allScopes_;
    Scope* currentScope_ = nullptr;
};
```

## 4. Semantic Rules Matrix

| Construct | Rule / Constraint | Diagnostic Message Example |
|---|---|---|
| `decl_stmt` | Pointers forbidden in local declarations | `local variable cannot have pointer type 'i32*'` |
| `decl_stmt` | Initializer required & type must match | `cannot initialize variable of type 'i32' with rvalue of type 'f32'` |
| `decl_stmt` | No re-declaration in same scope | `redefinition of variable 'x'` |
| `lvalue = expr` | Variable must be declared | `use of undeclared identifier 'x'` |
| `lvalue = expr` | Base of index must be pointer | `subscripted value is not a pointer (type is 'i32')` |
| `lvalue = expr` | Index must be `i32` | `array subscript is not an integer (type is 'f32')` |
| `lvalue = expr` | RHS type must match LHS | `assigning to 'i32' from incompatible type 'f32'` |
| `BinaryExpr (+ - * /)` | Both operands same (`i32` or `f32`) | `invalid operands to binary expression ('i32' and 'f32')` |
| `BinaryExpr (%)` | Both operands `i32` | `invalid operands to modulo expression ('f32' and 'f32')` |
| `BinaryExpr (& \| ^ << >>)` | Both operands `i32` | `bitwise operator requires integer operands ('f32' given)` |
| `Relational (< <= > >=)` | Both `i32` or both `f32`; yields `bool` | `comparison between incompatible types ('i32' and 'f32')` |
| `Logical (&& \|\|)` | Both operands `bool`; yields `bool` | `logical operator requires bool operands` |
| `UnaryExpr (-)` | Operand `i32` or `f32` | `invalid argument type 'bool' to unary minus` |
| `UnaryExpr (!)` | Operand `bool` | `invalid argument type 'i32' to logical not` |
| `UnaryExpr (~)` | Operand `i32` | `invalid argument type 'f32' to bitwise not` |
| `CallExpr (builtin)` | `tid_x()`, `ctaid_x()`, `ntid_x()` | `builtin 'tid_x' expects 0 arguments` |
| `CallExpr (cast)` | `i32(f32)` or `f32(i32)` | `explicit conversion expects 1 argument` |
| `If / While / For` | Condition expression must be `bool` | `statement condition must have type 'bool' (got 'i32')` |
| `ReturnStmt` | Must have no return expression | `kernel cannot return a value` |

## 5. AST Reference Interpreter (`Oracle O1`)

### 5.1 Value Model
```cpp
struct Value {
    enum class Kind { I32, F32, Bool } kind;
    union {
        int32_t i32;
        float f32;
        bool b;
    };
};
```

### 5.2 Thread Context & Simulated Memory
* A simulated launch takes:
  * `gridDim`: number of thread blocks (e.g., 4)
  * `blockDim`: number of threads per block (e.g., 256)
  * Named memory buffers: e.g. `n = 1000`, `a = 2.5f`, `x = [...]`, `y = [...]`.
* The runner executes sequentially:
  ```cpp
  for (int blockIdx = 0; blockIdx < gridDim; ++blockIdx) {
      for (int threadIdx = 0; threadIdx < blockDim; ++threadIdx) {
          int tid = blockIdx * blockDim + threadIdx;
          // Set thread registers: %tid.x = threadIdx, %ctaid.x = blockIdx, %ntid.x = blockDim
          executeThread(kernel, threadIdx, blockIdx, blockDim);
      }
  }
  ```

### 5.3 UB Trap Trapping Logic
* **DivZero:** If evaluating `/` or `%` with integer RHS == 0 $\rightarrow$ `throw UBTrap("division by zero")`.
* **DivOverflow:** If LHS == `INT32_MIN` and RHS == `-1` $\rightarrow$ `throw UBTrap("signed integer division overflow")`.
* **ShiftBounds:** If evaluating `<<` or `>>` with RHS $< 0$ or RHS $\ge 32$ $\rightarrow$ `throw UBTrap("shift count out of range")`.
* **BufferBounds:** When evaluating `buf[idx]`, look up buffer bounds; if `idx < 0 || idx >= buf.size()` $\rightarrow$ `throw UBTrap("buffer access out of bounds")`.
* **FloatToInt:** When evaluating `i32(floatVal)`, if `std::isnan(floatVal)` or `floatVal < INT32_MIN` or `floatVal > INT32_MAX` $\rightarrow$ `throw UBTrap("float to int conversion out of range / NaN")`.
* **StepLimit:** Loop counter tracks statement iterations. If `steps > maxSteps` (default $10^6$) $\rightarrow$ `throw UBTrap("step limit exceeded (infinite loop)")`.

## 6. Acceptance Criteria

1. **Symbol Table & Sema:**
   * Passes $\ge 20$ negative sema tests covering every rule in the matrix.
   * Successfully validates `saxpy.kc`.
2. **Interpreter:**
   * Evaluates arithmetic, comparisons, bitwise ops, loops, and conditions accurately.
   * Passes simulated GPU launch of `saxpy.kc`, matching expected mathematical results.
   * Catches every UB condition in dedicated unit tests.
3. **CLI:**
   * `kcc --run-ast <file.kc>` executes kernels with customizable grid, block, and buffer inputs.
4. **All GoogleTest suites pass 100% with zero compiler warnings.**
