## 1. Objectives

1. Design an explicit, typed **Abstract Syntax Tree (AST)** representing all constructs in the KC language (`Program`, `KernelDecl`, `ParamDecl`, `Stmt` hierarchy, `Expr` hierarchy, `Type`).
2. Implement a hand-written **Recursive-Descent Parser** matching the precedence hierarchy in `docs/grammar.md`.
3. Implement **Panic-Mode Error Recovery** synchronizing on statement boundaries (`;`, `}`) so that invalid syntax produces meaningful diagnostics without cascading bogus errors or crashing.
4. Implement an **AST Pretty-Printer** and integrate CLI flag `kcc --dump-ast <file.kc>` to dump human-readable tree representations.
5. Implement the **`gate-lab` tool** (`tools/gate-lab/`) to compute **FIRST** sets, **FOLLOW** sets, and construct **LL(1) parsing tables** with conflict reporting for GATE CS revision.
6. Deliver a comprehensive unit test suite covering:
   * Operator precedence and associativity.
   * Full AST construction for realistic GPU kernels (`saxpy.kc`).
   * Panic-mode syntax error recovery (reporting multiple distinct errors).
   * `gate-lab` validation against textbook grammars with hand-computed expected FIRST/FOLLOW sets.

## 3. AST Data Structures

```cpp
namespace ptxlab {

// 1. Types
enum class PrimitiveType { I32, F32, Bool, Void };

struct Type {
    PrimitiveType primitive = PrimitiveType::Void;
    bool isPointer = false; // Pointers are only allowed as kernel parameters (global memory)
    
    bool isInt() const noexcept { return primitive == PrimitiveType::I32 && !isPointer; }
    bool isFloat() const noexcept { return primitive == PrimitiveType::F32 && !isPointer; }
    bool isBool() const noexcept { return primitive == PrimitiveType::Bool && !isPointer; }
    bool isPtr() const noexcept { return isPointer; }
    std::string toString() const;
};

// 2. Base AST Node
class ASTVisitor;

class ASTNode {
public:
    explicit ASTNode(SourceLocation loc) : loc_(loc) {}
    virtual ~ASTNode() = default;
    
    SourceLocation location() const noexcept { return loc_; }
    virtual void accept(ASTVisitor& visitor) = 0;

private:
    SourceLocation loc_;
};

// 3. Expressions
class Expr : public ASTNode {
public:
    using ASTNode::ASTNode;
};

class IntLiteralExpr : public Expr { ... };
class FloatLiteralExpr : public Expr { ... };
class BoolLiteralExpr : public Expr { ... };
class IdentifierExpr : public Expr { ... };
class UnaryExpr : public Expr { ... };   // -, !, ~
class BinaryExpr : public Expr { ... };  // +, -, *, /, %, &, |, ^, <<, >>, ==, !=, <, <=, >, >=, &&, ||
class IndexExpr : public Expr { ... };   // base[idx]
class CallExpr : public Expr { ... };    // tid_x(), ctaid_x(), ntid_x(), i32(x), f32(x)

// 4. Statements
class Stmt : public ASTNode {
public:
    using ASTNode::ASTNode;
};

class CompoundStmt : public Stmt { ... }; // { stmt* }
class DeclStmt : public Stmt { ... };     // type x = expr;
class AssignStmt : public Stmt { ... };   // lvalue = expr;
class IfStmt : public Stmt { ... };       // if (cond) thenStmt [else elseStmt]
class WhileStmt : public Stmt { ... };    // while (cond) body
class ForStmt : public Stmt { ... };      // for (init; cond; step) body
class ReturnStmt : public Stmt { ... };   // return;

// 5. Kernel Declaration & Program
class ParamDecl : public ASTNode { ... }; // type x
class KernelDecl : public ASTNode { ... };// kernel name(params) { body }
class Program : public ASTNode { ... };   // kernel*
}
```

## 4. Parser Algorithm & Error Recovery

### 4.1 Recursive Descent Architecture
* Expression parser uses precedence functions:
  `parseExpr()` $\to$ `parseLogicalOr()` $\to$ `parseLogicalAnd()` $\to$ `parseBitwiseOr()` $\to$ `parseBitwiseXor()` $\to$ `parseBitwiseAnd()` $\to$ `parseEquality()` $\to$ `parseRelational()` $\to$ `parseShift()` $\to$ `parseAdditive()` $\to$ `parseMultiplicative()` $\to$ `parseUnary()` $\to$ `parsePostfix()` $\to$ `parsePrimary()`.
* Every precedence level builds left-associative binary trees iteratively via loops without stack overflow.

### 4.2 Panic-Mode Synchronization
When a syntax error occurs (e.g. malformed expression or missing token):
1. Emit a clear diagnostic pointing to the offending token location.
2. Advance through tokens until encountering a synchronization token:
   * Semicolon (`;`) terminates the bad statement; consume it and resume parsing next statement.
   * Right brace (`}`) terminates the enclosing block; leave it for the block parser.
   * Keyword (`kernel`, `if`, `while`, `for`, `return`) marks the start of a new statement.
3. This allows the compiler to report multiple real syntax errors in a single run.

## 5. `gate-lab` Tool Architecture

### 5.1 Formal Grammar Representations
```cpp
struct Symbol {
    std::string name;
    bool isTerminal;
};

struct Production {
    Symbol lhs;
    std::vector<Symbol> rhs; // Empty RHS denotes epsilon (ε)
};

class Grammar {
    Symbol startSymbol;
    std::vector<Symbol> nonTerminals;
    std::vector<Symbol> terminals;
    std::vector<Production> productions;
};
```

### 5.2 Algorithms
1. **FIRST Sets Calculation:**
   * Iterative fixed-point algorithm over all symbols.
   * If $X$ is terminal, $\text{FIRST}(X) = \{X\}$.
   * If $X \to Y_1 Y_2 \dots Y_k$: add $\text{FIRST}(Y_1) \setminus \{\epsilon\}$. If $Y_1 \Rightarrow^* \epsilon$, continue adding $\text{FIRST}(Y_2)$, etc.
2. **FOLLOW Sets Calculation:**
   * Place `$` in $\text{FOLLOW}(S)$.
   * For production $A \to \alpha B \beta$: add $\text{FIRST}(\beta) \setminus \{\epsilon\}$ to $\text{FOLLOW}(B)$. If $\beta \Rightarrow^* \epsilon$, add $\text{FOLLOW}(A)$ to $\text{FOLLOW}(B)$.
   * Repeat until fixed point.
3. **LL(1) Table Construction:**
   * For each production $A \to \alpha$:
     * For each terminal $a \in \text{FIRST}(\alpha)$, add $A \to \alpha$ to $M[A, a]$.
     * If $\epsilon \in \text{FIRST}(\alpha)$, for each $b \in \text{FOLLOW}(A)$ (including `$`), add $A \to \alpha$ to $M[A, b]$.
   * If any entry $M[A, a]$ receives $> 1$ production, report an **LL(1) conflict** with the conflicting productions.

2. **CLI Integration:**
   * `kcc --dump-ast <file.kc>` dumps formatted indented AST to stdout.
3. **`gate-lab` CLI & Tests:**
   * `gate-lab --grammar <grammar.txt>` outputs FIRST/FOLLOW sets and LL(1) parse table.
   * Unit tests on standard textbook grammars verify hand-calculated FIRST/FOLLOW sets.
4. **All CTest suites pass 100% green with zero warnings.**
